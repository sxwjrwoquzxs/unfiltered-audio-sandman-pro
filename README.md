## Overview

Unfiltered Audio Sandman Pro is a unique delay and freeze effect that captures spectral snapshots of audio and blurs, stretches, or repeats them to create dreamy, ambient soundscapes.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Unfiltered Audio Sandman Pro** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Spectral Freeze** | Capture and hold spectral snapshots for infinite sustain effects |
| **Dream Delay** | Multi-tap delay with spectral smearing for ethereal echoes |
| **Modulation** | LFO and envelope modulate freeze position and delay time |
| **Ducking** | Sidechain-controlled freeze amount for rhythmic gating effects |
